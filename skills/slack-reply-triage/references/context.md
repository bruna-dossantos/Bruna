## Draft tone rules
- Direct, practical, no filler phrases
- Healthcare terminology used naturally (not over-explained)
- Acknowledge the ask, answer it, offer next step
- Never start with "Hope you're doing well" or "Thank you for reaching out"
- Warm with direct reports, efficient with everyone else
- Short: 1-3 sentences unless complexity requires more
